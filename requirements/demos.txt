# Demos set, the default install: the core set plus matplotlib for the scripts
# in benchmarks/ and demos/, and pygame for contract_uav_core/viz/live_visualizer.py
# (used by demos/demo_waypoint_mission.py and demos/demo_sensor_degradation.py).
# From the repository root:
#   python -m pip install -e ./contract_uav_core -r requirements/demos.txt
#
# It does NOT include pacti. Without pacti the horizon planner is silently
# disabled, so benchmarks/benchmark_controllers.py does not reproduce
# docs/RESULTS.md section 1 (Adaptive mission time 63.240 s instead of
# 53.780 s). Use pacti.txt for that.
#
# Python floor: 3.7
#   - Set by core.txt (numpy 1.20.0: >=3.7).
#   - matplotlib 3.3.0 declares Requires-Python >=3.6; pygame 2.0.0 declares
#     none and pygame 2.6.1 declares >=3.6.
#   Note: pygame 2.6.1, the newest release, ships wheels only up to CPython 3.13.
#   Python below 3.10 has not been exercised.
-r core.txt
matplotlib>=3.3.0
pygame>=2.0.0
