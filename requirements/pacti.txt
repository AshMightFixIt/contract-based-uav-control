# Pacti set: the demos set plus an exact pacti pin. Pacti is needed only offline:
# for `make test-pacti`, and for planning/export_contracts.py, which writes the
# planner's limits to contract_uav_core/config/contracts.json. The horizon planner
# runs without pacti, so benchmarks/benchmark_controllers.py gives the same
# results with or without it (Adaptive mission time 54.320 s).
#
# Python floor: 3.10
#   - pacti 0.3.1 declares Requires-Python >=3.10 on PyPI and requires
#     numpy>=2.2.6 (>=3.10), scipy>=1.15.3 (>=3.10), matplotlib>=3.10.9 (>=3.10).
#   - Consequence: this set always installs NumPy 2.x.
#   pacti 0.2.0 (Requires-Python <3.12,>=3.8) gave identical section 1 results
#   in an earlier verification, but it is not the pin used here.
-r demos.txt
pacti==0.3.1
