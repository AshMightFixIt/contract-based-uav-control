# Default install (`pip install -r requirements.txt`). It resolves the three
# requirements from before the dependency sets were split out
# (numpy>=1.20.0, matplotlib>=3.3.0, pygame>=2.0.0) plus PyYAML>=5.4.1 for the
# airframe files (requirements-runtime.txt).
# The core package is installed separately, from the repository root:
#   python -m pip install -e ./contract_uav_core
#
# It does NOT include pacti. Without pacti the horizon planner is silently
# disabled, so benchmark_controllers.py does not reproduce RESULTS.md section 1
# (Adaptive mission time 63.240 s instead of 53.780 s). Use
# requirements-legacy.txt for that.
#
# Python floor: 3.7 (numpy 1.20.0 declares >=3.7; see requirements-runtime.txt
# and requirements-viz.txt). Python below 3.10 has not been exercised.
