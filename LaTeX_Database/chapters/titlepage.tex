\begin{center}
    {\Large\bfseries Abstract}
\end{center}

\vspace{0.5cm}

\noindent
This document presents a comprehensive technical specification of a \textbf{Contract-Based Adaptive UAV Control System} that advances the state-of-the-art in autonomous drone safety through the application of formal methods.

The system implements \textbf{Assume-Guarantee (A/G) contracts} at every interface, providing mathematically verifiable safety guarantees while enabling adaptive behavior under varying environmental conditions. Using the \textbf{Pacti library} for polyhedral contract composition, the system can formally verify mission feasibility before takeoff and continuously monitor contract satisfaction during flight.

The architecture features a \textbf{horizon-based predictive planner} that cascades contracts over a planning horizon to anticipate safety violations before they occur. This enables preemptive controller switching between an efficient \textbf{PID controller} (for nominal conditions) and a robust \textbf{H-infinity controller} (for degraded conditions), with \textbf{Control Barrier Functions (CBF)} providing runtime safety enforcement as the last line of defense.

Key contributions include:
\begin{itemize}[leftmargin=*,itemsep=3pt]
    \item A hierarchical contract framework covering sensors, estimation, control, and actuation
    \item Predictive horizon planning using formal contract composition
    \item Principled adaptive control with mathematically justified switching conditions
    \item Graceful degradation through multiple fallback layers
    \item Transparent decision-making through contract-based reasoning
\end{itemize}

Experimental results demonstrate the system's ability to complete multi-waypoint missions while automatically adapting to wind disturbances, with smooth transitions between controllers and zero safety violations.

\vspace{1cm}

\noindent\textbf{Keywords:} Unmanned Aerial Vehicles, Assume-Guarantee Contracts, Adaptive Control, Formal Verification, Control Barrier Functions, Pacti, Safety-Critical Systems
